2. WORKFLOW: YE KAAM KAISE KARTA HAI?
-------------------------------------------------------------
Jab hum URL daalte hain (e.g. testphp.vulnweb.com) aur "Scan" dabate hain, toh backend 7 stages me kaam karta hai:

Phase 1: Target Classification
Check karta hai ki URL legal/demo hai ya nahi (taaki google.com jaise secure sites par illegal bruteforce na ho).

Phase 2: DNS Reconnaissance (Passive/Active)
Backend Node.js ka `dns` module use karta hai. Target domain ka IP address (A record), Mail server (MX), aur TXT records (SPF/DMARC) nikalta hai. Isse pata chalta hai ki unka email spoof ho sakta hai ya nahi.

Phase 3: HTTP Security Header Audit
Target ke server ko ping karta hai aur headers check karta hai (HSTS, CSP, X-Frame-Options). Agar ye missing hain, toh Clickjacking aur XSS attack easily ho sakta hai.

Phase 4: TCP Port Scanning (Active)
Ye bohot important step hai. Humne custom port scanner likha hai Node.js ke `net` socket use karke. Ye ports jaise 80 (HTTP), 443 (HTTPS), 22 (SSH), 3306 (MySQL) par TCP handshake karta hai. Jo open hote hain, unka status log karta hai.

Phase 5: Directory Fuzzing / Bruteforcing (Active)
System background me ek payload list (`/.env`, `/admin`, `/.git/config`, `/backup.zip`) ke liye `HTTP HEAD` requests bhejta hai. Agar server HTTP 200 ya 403 status code deta hai, iska matlab waha sensitive file exposed hai.

Phase 6: Application Layer Vulnerability Testing (Active SQLi)
Engine deliberately ek SQL injection payload (jaise URL me `1'`) bhejta hai, aur agar uske response me "mysql_fetch_array()" ya SQL syntax error aata hai, toh engine usko catch kar leta hai aur "Critical SQLi" finding generate karta hai. Ye 100% real attack check hai. (Sath me demo UI populate karne ke liye known heuristic vulns bhi map hoti hain).

Phase 7: Risk Scoring & OWASP Mapping
Saari vulnerabilities aane ke baad, unko OWASP Top 10 framework (jaise A01: Broken Access Control, A03: Injection) me map kiya jata hai. Unka CVSS (Common Vulnerability Scoring System) calculate hoke total Risk Score nikalta hai (Out of 10).

4. HOW IS RISK SCORE CALCULATED? (Math Logic)
-------------------------------------------------------------
Risk score = total weighted severity.
- Critical = 10 weight
- High = 7.5 weight
- Medium = 5 weight
- Low = 2.5 weight
Saari finding ke weight ko calculate karke ek capped algorithm me dala jata hai jisse final score hamesha 0.0 aur 10.0 ke beech (normalized) aaye. Agar website ka score >7 hai toh usko "Red/Critical" mana jata hai.
